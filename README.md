# Waddle to Run legal site

This directory contains the canonical Terms and Conditions and Privacy Policy for Waddle to Run, plus the Jekyll files used by the public GitHub Pages site.

Public URLs:

- https://spammusubitech.github.io/waddle-to-run/privacy/
- https://spammusubitech.github.io/waddle-to-run/terms/

The contents of this directory are published from the separate public `spammusubitech/waddle-to-run` repository so the public site name matches the app name.
